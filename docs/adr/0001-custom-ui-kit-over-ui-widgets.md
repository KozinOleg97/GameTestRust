# UI строится на `ui_widgets` и собственном ките

Поводом пересмотреть слой интерфейса стал переход на Bevy 0.20: `Interaction` и `ui::widgets::Button` там стали непригодны для внешних крейтов, и UI пришлось переписывать в любом случае. Решили собирать его из headless-виджетов `ui_widgets` (они входят в стандартные фичи Bevy) и тонкого кита проекта: `UiTheme` для вида, `ui/kit.rs` для спавна узлов, `ui/actions.rs` для действий.

Feathers отклонён, потому что его API меняется от релиза к релизу — в 0.20 переписана система темы на семантические токены, — и он навязывает «редакторный» вид, который пришлось бы подгонять под игру. BSN отклонён как нестабильный: его синтаксис менялся внутри перехода 0.19 → 0.20, а для игрового UI примеров мало. Оба варианта не запрещены: Feathers можно взять точечно под отдельные виджеты вроде слайдера, BSN — позже, и только на ось структуры.

## Consequences

Время жизни панели привязано к её контексту: оверлей производительности живёт всё приложение и переключает видимость, а панели симуляции и свойств гекса живут ровно столько, сколько состояние `Active`, и умирают через `DespawnOnExit`. Структура папок это повторяет: `ui/screens/` для того, что живёт по состояниям входа-выхода, `ui/hud/` для панелей поверх игры.

До унификации способов появления и исчезновения UI было три, и один из них — пересоздание узлов по нажатию клавиши.
